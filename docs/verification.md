# 짧은 확인 방법

1. 공개 사이트 URL을 새 시크릿 창에서 열고 첫 화면의 이름·한 줄 소개·이야기 입구를 확인합니다.
2. `이야기`에서 `2022년` 고난 장면, 먼저 인사하고 질문한 변화, `2026년` 현재 장면을 확인하고 `근거`에서 회복탄력성·과제지속력 수치와 출처를 확인합니다.
3. `대표작`에서 10번 논문 PDF와 13번 앱 자리, `지원 문서`에서 지원 DOCX를 열어 봅니다.
4. 장치 폴더에서 `npm install` 후 `npm run generate`, `npm run test:generator`, `npm run check:content`, `npm run check:privacy`, `npm run build`를 실행합니다.
5. `npm run test:generator`는 같은 입력을 두 임시 폴더에 두 번 처리해 출력 바이트가 같은지 확인합니다. 새 출석·제출 파일을 넣은 경우 `src/generated/` 결과가 바뀌는 것도 확인합니다.

## 제출물 위치

- 사이트: 배포 후 HTTPS URL 한 개
- 문서: `deliverables/김태빈_지원서_묶음.docx`
- 장치 ZIP: `deliverables/김태빈_BR-A_갱신장치.zip`
- 장치 실행 소스·README·최종 결과: ZIP 내부 `scripts/`, `inputs/`, `src/generated/`, `README.md`
- 요구사항 checklist: `checklist.md`
