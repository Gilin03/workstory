# 최종 콘텐츠 확인 필요

아래 세 항목은 과제의 “내 손으로 쓴 문장” 기준을 위해 제출 전에 직접 확인하고 수정합니다.

1. 첫 화면 한 줄 소개: `src/content/approved.json`의 `tagline`
2. 자기소개 본편 첫 문장: `src/content/approved.json`의 `story[0].text` 첫 문장
3. 자기소개 본편 마지막 문장: `src/content/approved.json`의 `story[2].text` 마지막 문장

현재 본편은 9번 서사의 1인칭 완성본과 확인된 리추얼 기록을 바탕으로 1,323자로 확장한 승인본입니다. 2022년 고난 → 먼저 인사하고 질문한 전환 → 2026년 경청·도움·정독·성장 기록의 순서를 유지합니다. 첫 문장과 마지막 문장은 제출 전에 본인이 최종 확인합니다.

출석 수치는 사용자가 제공한 화면에서 확인한 값만 사용합니다. 사이트에는 이야기 뒤 보조 근거로 `결석 0일`, `확정 출석 26/27일`, `오늘 확정 전 1일`을 표시하고, 각 값에 `내 출석 기록 · 기준일 2026.09.17`을 붙입니다. 출석률은 표시하지 않습니다. 최신 출석을 반영할 때는 `inputs/attendance.json`을 새 원자료로 교체한 뒤 `npm run generate`를 실행합니다. 핵심 근거는 리추얼 기록의 `23회 실천`과 `26일 기록`입니다.

숫자와 출처는 자기소개를 대신하지 않습니다. 사이트에서 본편과 세 능력의 장면을 먼저 읽은 뒤, 회복탄력성과 과제지속력이 반복 기록으로 이어졌는지 확인하는 순서입니다.

공개 연락 수단은 `contact.email`에 사용자가 공개하기로 한 이메일을 넣고 `isPlaceholder`를 `false`로 둡니다. 현재는 `xoqls081215@gmail.com`을 반영했습니다.
